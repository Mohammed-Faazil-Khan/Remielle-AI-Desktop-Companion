# Remielle-AI-Desktop-Companion
This is my first experiment with NVIDEA's nemotron model.
The project is based on Project Riko by Rayen.
The AI Entity is capable of manupulating files and writing complex code scripts.
It also comes with Spotify API which enables it to play, pause and create playlists spontaneously according to the user's taste.
The Minecraft mod works on local system and is in process of being optimised for users.
